A tiny program that writes a short poem about stopping — the power to stop and to stay, whether a person's, an AI agent's, or the agency that passes between them when one acts for the other.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

This writes `entry.txt` (the poem, 229 Unicode code points) into the output directory.
